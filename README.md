# Freaches - Fast Food & Panini Delivery App 🍔🥪

## Project Description
A full-stack web application designed for a fast-food delivery service, with a core specialty in signature sandwiches and panini. The system provides a seamless user experience for browsing the menu, managing a shopping cart, and securely placing orders. The project is built using a modern tech stack, featuring an Angular frontend and a RESTful API backend powered by Django Rest Framework.

## Core Features & Implementation
* **JWT Authentication:** Secure user registration, login, and logout processes using HttpInterceptors.
* **Product Catalog:** Dynamic menu rendering with filtering capabilities.
* **Smart Shopping Cart:** Client-side state management for cart items.
* **Order Processing (CRUD):** Full integration with the Django backend for creating, reading, updating, and deleting orders.
* **Offline-First Fallback:** A built-in fail-safe mechanism that saves orders locally (LocalStorage) if the backend server is temporarily unavailable.
* **API Integration:** Seamless communication between Angular services and Django DRF.

## Tech Stack
* **Frontend:** Angular (v17+), TypeScript, HTML/CSS
* **Backend:** Python, Django, Django Rest Framework (DRF)
